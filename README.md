## ทำอะไรได้บ้าง

แก้ไขคำในไฟล์ PDF เพิ่มข้อความ ไฮไลต์ และปิดทับ · รวมหลายไฟล์เป็นไฟล์เดียว · หมุน ลบ สลับ และแทรกหน้า · กรอกข้อมูลและลงนาม · ใส่ลายน้ำ · หัวกระดาษ/ท้ายกระดาษพร้อมเลขหน้าแบบเลขไทย · แยกไฟล์และดึงหน้า · แปลง PDF เป็น Word, ข้อความ, PNG, JPG และรวมรูปเป็น PDF · ธีมมืด · เมนูไทย/อังกฤษ

## ดาวน์โหลด

| ระบบ | ไฟล์ |
|---|---|
| Mac (macOS 11 ขึ้นไป, ชิป M และ Intel) | [TigerCraft-0.1.0-mac.dmg](../../releases/latest/download/TigerCraft-0.1.0-mac.dmg) |
| Windows 64 บิต (ไม่ต้องติดตั้ง) | [TigerCraft-0.1.0-windows-x64.zip](../../releases/latest/download/TigerCraft-0.1.0-windows-x64.zip) |

รหัส SHA-256 สำหรับตรวจไฟล์อยู่ในไฟล์ `SHA256SUMS.txt` ของแต่ละรุ่น

**เปิดครั้งแรกบน Mac (macOS 15 ขึ้นไป):** เปิดแอป › กด "เสร็จสิ้น" › การตั้งค่าระบบ › ความเป็นส่วนตัวและความปลอดภัย › เลื่อนลงล่างสุด › "เปิดต่อไป" (Open Anyway)
**macOS 11–14:** คลิกขวาที่แอป › เปิด › เปิด

**เปิดครั้งแรกบน Windows:** แตกไฟล์ zip ก่อน › ดับเบิลคลิก TigerCraft.exe › ถ้าขึ้น "Windows protected your PC" ให้กด More info › Run anyway

คำเตือนเหล่านี้ขึ้นเพราะ TigerCraft ยังไม่ได้ลงทะเบียนนักพัฒนากับ Apple และ Microsoft
