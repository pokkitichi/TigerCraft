นโยบายความเป็นส่วนตัว TigerCraft
ฉบับวันที่ 5 พฤศจิกายน 2569

สรุปสั้น ๆ: TigerCraft ทำงานบนเครื่องของคุณทั้งหมด ไม่เก็บ ไม่ส่ง และไม่ขายข้อมูลของคุณ

1. ไฟล์ PDF และเอกสารของคุณ
   TigerCraft เปิด แก้ไข และบันทึกไฟล์บนเครื่องของคุณเท่านั้น
   โปรแกรมไม่อัปโหลดไฟล์ไปที่เซิร์ฟเวอร์ใด และใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต

2. ข้อมูลที่โปรแกรมเก็บไว้บนเครื่องของคุณ
   เพื่อให้ใช้งานสะดวก โปรแกรมอาจเก็บข้อมูลต่อไปนี้ไว้ในเครื่องของคุณเอง
   - การตั้งค่า เช่น ภาษา ธีมสว่าง/มืด
   - รายชื่อไฟล์ที่เปิดล่าสุด
   - ลายเซ็นที่คุณบันทึกไว้ในเมนู "ลายเซ็นของฉัน"
   ข้อมูลเหล่านี้ไม่ถูกส่งออกจากเครื่อง ถ้าใช้คอมพิวเตอร์ร่วมกับผู้อื่น
   ควรลบลายเซ็นที่บันทึกไว้เมื่อเลิกใช้ (กดลบได้ในหน้าลายเซ็นของฉัน)

3. ไม่มีการติดตามการใช้งาน
   TigerCraft ไม่มีระบบโฆษณา ไม่มีระบบวิเคราะห์การใช้งาน (analytics)
   และไม่มีระบบส่งรายงานอัตโนมัติ

4. เว็บไซต์ดาวน์โหลด
   เว็บไซต์ของ TigerCraft ให้บริการโดย GitHub Pages
   เว็บไซต์ไม่ใช้คุกกี้และไม่มีระบบติดตามผู้เข้าชมของผู้พัฒนา
   แต่ GitHub อาจบันทึกข้อมูลทางเทคนิค เช่น หมายเลข IP ตามนโยบายของ GitHub
   (https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)

5. การสนับสนุนผ่านพร้อมเพย์
   การโอนเงินทำผ่านแอปธนาคารของคุณโดยตรง ผู้พัฒนาจะเห็นเฉพาะข้อมูลที่ธนาคาร
   แสดงในรายการรับเงิน เช่น ชื่อผู้โอนและจำนวนเงิน ผู้พัฒนาจะไม่นำข้อมูลนี้
   ไปใช้เพื่อวัตถุประสงค์อื่น และจะไม่เปิดเผยชื่อผู้สนับสนุนโดยไม่ได้รับอนุญาต

6. การเปลี่ยนแปลงนโยบาย
   หากรุ่นใหม่ของโปรแกรมมีการเปลี่ยนแปลงเรื่องข้อมูล เช่น เพิ่มการตรวจหาอัปเดตผ่านอินเทอร์เน็ต
   ผู้พัฒนาจะแจ้งในหน้าดาวน์โหลดและปรับนโยบายนี้ก่อน
